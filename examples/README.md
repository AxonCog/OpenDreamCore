# 示例页面

## 客户端模组示例 (mod/)

丢进客户端 `.minecraft/OpenDreamCore/UI/` 目录即可使用。

| 文件 | 说明 |
|---|---|
| `welcome.yaml` | 综合演示页（按钮/图片/文字/动画/子页） |
| `hud.yaml` | HUD 常驻界面示例 |
| `container.yaml` | 容器替换示例 |
| `hologram.yaml` | 世界全息面板示例 |
| `card_tpl.yaml` | 卡片模板（embed 引用） |
| `embed_target.yaml` | 嵌入目标页（embed 组件加载） |

## 服务端插件示例 (plugin/)

丢进服务端 `plugins/OpenDreamCore/UI/` 目录。

| 文件 | 说明 |
|---|---|
| `shop.yaml` | 简易商店（点格子购买） |
| `container.yaml` | 容器替换（含 playerInventory 背包区） |
| `menu.yaml` | 主菜单（多子页导航） |
| `hud.yaml` | 服务端 HUD（变量推送实时刷新） |
| `hud_global.yaml` | 全体 HUD |
| `hud_hide.yaml` | hideVanilla 演示（隐藏原版 HUD） |
| `world_board.yaml` | 世界全息公告板 |
| `world_quest.yaml` | 世界任务追踪面板 |
| `world_fixed.yaml` | 世界固定锚点面板 |
