# OpenDreamCore 协议（v1）

> 自研二进制协议。命名空间 `opendreamcore:*`。
> 本草案是实现依据；实现以 common 编解码代码为准。

## 0. 通则

- 通道：Minecraft 自定义 payload（`opendreamcore:*`），NeoForge 客户端 ↔ Paper 服务端
- 传输：客户端 NeoForge 注册 playToServer/playToClient 通道，走 vanilla `minecraft:custom_payload`；
  服务端 Paper 对未注册通道由 Bukkit messenger 兜底（`PluginMessageListener`），
  下发用 `Player#sendPluginMessage`。两端都是**协议消息完整二进制**（OdcByteArrayBuf 编解码）
- 字节序：大端（与 MC FriendlyByteBuf 一致）
- 字符串：UTF-8，前缀 varint 长度
- 版本协商：握手阶段交换协议版本 + 模组版本
- 安全：服务端权威裁决；ui_event 带序列号防重放；包体上限 1MB

## 1. 消息集

### 握手
| 消息 | 方向 | 内容 |
|---|---|---|
| ready | C→S | 协议版本(varint)、客户端模组版本(string)、能力位(byte) |
| ready_ack | S→C | 协议版本、服务端模组版本、能力位、云资源会话密钥(byte[]，AES-128-GCM key，可空) |

能力位（bit 0-7）：允许本地UI / 支持云资源 / 支持tooltip / 支持编辑器 …

### 页面
| 消息 | 方向 | 内容 |
|---|---|---|
| page_sync | S→C | 页面 id + **YAML 原文**（客户端本地解析入库，保留注释排版） |
| page_control | S→C | 动作(byte)：open/close/sub_open/sub_close/move；页面id、会话id、父会话id（move 时复用为 "x,y"） |
| state_patch | S→C | 会话id + 变量补丁表（整数/小数/布尔/字符串/null 类型标记，key 支持点路径） |

### 交互
| 消息 | 方向 | 内容 |
|---|---|---|
| ui_event | C→S | 会话id、元素id、触发(byte)、序列号(long)、参数 |
| item_action | C→S | 槽位动作（取/放/换），服务端裁决（规划） |
| item_action_result | S→C | 裁决结果（规划） |
| tooltip_registry | S→C | 服务端 tooltip 全量（元素 id → 文本，可插值） |
| tooltip_resync | C→S | 进服拉取 tooltip 注册表请求 |
| global_state | S→C | 服务端全局变量（在线人数/服务器名等，周期广播） |

### 编辑器
| 消息 | 方向 | 内容 |
|---|---|---|
| editor_lease | 双向 | 租约请求/释放/授予/拒绝（同页单编辑者，10 分钟过期） |
| editor_save | C→S | 页面 YAML 回写（校验租约后落盘 + 热重载 + 广播） |
| page_layout | 双向 | 元素位置补丁：C→S 保存（校验租约）/ S→C 广播与打开附带 |

### 资源云
| 消息 | 方向 | 内容 |
|---|---|---|
| cloud_manifest | S→C | 文件清单（路径/大小/SHA-256） |
| cloud_diff | C→S | 缺失/不一致的文件路径列表 |
| cloud_file | S→C | 单文件密文（AES-128-GCM，iv 前缀；空 key 直写） |
| cloud_delete | S→C | 删除指令（路径列表） |
| cloud_done | S→C | 同步完成 |

### 版本校验
- 随 ready/ready_ack 交换版本号；客户端对比显示 `客户端红 → 服务器绿`，
  `versionCheck.enforce`（客户端本地配置）为 true 时协议不匹配自动断开

### 编辑器（后续）
| 消息 | 方向 | 内容 |
|---|---|---|
| editor_lease / snapshot / save | 双向 | 租约 + 分块快照 + 保存 |

## 2. 页面模型

- 页面由 **page_sync 下发 YAML 原文**，客户端用 ConfigParser SPI（YAML 默认）解析为页面模型
- 布局表达式（x/y/width/height）在客户端用 DreamLang 求值（window/parent/this/vars 上下文）
- 元素 actions 脚本在**服务端**执行（服务端裁决），命名空间方法走服务端注册表

## 3. 安全

- 包体上限 1MB，大文件分块
- ui_event 序列号单调递增，服务端丢弃重复/乱序
- 服务端裁决：商店/容器/物品全部服务端执行
- 资源云：SHA-256 校验 + AES-128-GCM 会话密钥加密（密钥随 ready_ack 下发）

## 4. 版本

- 协议版本 v1（首版）；不兼容变更递增主版本，兼容变更递增次版本
