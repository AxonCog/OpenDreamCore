## 梦想核心首个开源版本

## 包含

- **客户端模组**（NeoForge + Fabric 1.21.1）
- **服务端插件**（Bukkit / Paper）

## 功能

- 30+ 种 UI 元素（文本 / 图片 / 视频 / 按钮 / 滑块 / 容器 / 图表 / 全息面板…）
- 游戏内可视化编辑器（拖拽排序 · 属性检查器 · 实时预览）
- DreamLang 脚本语言（中英双语）
- 世界空间全息面板 + NPC 对话气泡
- 资源云分发（增量加密同步）
- 服务端裁决（商店 / 容器 / 权限）

## 其他版本

1.6.4 ~ 1.7.10 / 1.12.2 / 1.16.5 / 1.20.1 / 1.21.4+ / 26.1.2 都有对应构建，见仓库根目录的 OpenDreamCore-Legacy 与 targets。

## 安装

| 文件 | 放置位置 |
|---|---|
| `OpenDreamCore-neoforge-1.21.1-0.1.0.jar` | 客户端 `mods\` 文件夹 |
| `OpenDreamCore-fabric-1.21.1-0.1.0.jar` | 客户端 `mods\` 文件夹（Fabric） |
| `OpenDreamCore-Plugin-0.1.0.jar` | 服务端 `plugins\` 文件夹 |
