## 一、设计哲学：为什么是这门样子

DreamLang 的目标用户不是程序员，是**服主和页面作者**。所以它有几个刻意的取舍：

1. **中英双语关键字**。`if` 和 `如果` 完全等价，`return` 和 `返回` 完全等价。
   你可以全英文写，可以全中文写，也可以一句话里混着来，解析器根本不关心。
2. **标识符支持中文**。`玩家血量`、`背景图宽度` 都是合法变量名。
   变量名叫什么由你决定，不用为了"能写"而翻译成拼音。
3. **表达式即语句**。`x + 1` 单独一行也是合法语句（求值后丢弃）。
   配合三元和赋值表达式，一行流写法非常顺。
4. **零样板**。没有 main 函数，没有分号强迫症（可写可不写），没有类型声明。
   `变量 血量 = 100` 就是全部。

代价也有，先说清楚：数字只有一种（双精度浮点），没有整数类型；
动态类型，拼错变量名不会在编译期报错而是得到 `null`。
自由是有价格的，这份手册就是帮你把价格花在刀刃上。



## 二、三分钟速览

一段真实感的脚本，覆盖八成常用语法：

```text
// 变量：var/let/变量 三选一；const/常量 声明常量
变量 金币 = 100
const 折扣 = 0.8

// 条件：if/如果 … else/否则
if (金币 >= 100) {
    金币 = 金币 * 折扣
    Toast.显示("购买成功")
} 否则 {
    Toast.显示("钱不够")
}

// 循环四件套
当 (金币 < 50) { 金币 = 金币 + 1 }          // while/当
for (变量 i = 0; i < 3; i++) { 打印(i) }    // 经典 for
循环 (3, { 打印("再来一次") })               // loop 次数 + 块
遍历 (数组, item, idx, arr) { 打印(item) }   // for_each

// 函数与返回
函数 折后价(原价) {
    返回 原价 * 折扣
}

// Lambda：传给事件总线或高阶用法
Event.订阅("boss_killed", (name) => { Toast.显示(name + " 团灭") })

// 异常保护
尝试 {
    危险操作()
} 捕获 (错误) {
    打印("出错了: " + 错误)
}
```



## 三、词法基础

### 3.1 标识符：中文是一等公民

```
合法：金币、playerName、背景_宽度、i2
规则：中文开头（后面可跟中文/英文/数字），或英文/下划线开头
非法：2ch（数字开头）、我的-变量（连字符是减号）
```

### 3.2 字符串

```text
"双引号"        '单引号'       // 都行，\ 转义
"&c红色文字"     // & 色码开头整体是一个字符串字面量
"§a绿色文字"     // § 同理
```

`&c离开副本` 这种写法不需要引号包裹也是字符串，MC 色码是词法级支持，
写提示语时少敲一对引号。

### 3.3 数字与布尔

```text
123   3.14   0.5           // 全部是双精度浮点，没有整数类型
true / 真                  false / 假
null / 空值
```

负数用一元减号：`-5` 是"对 5 取负"，不是字面量。

### 3.4 注释

```text
// 行注释
/* 块注释，可以
   跨很多行 */
```

### 3.5 分号

可有可无。换行和分号都是合法的语句分隔，团队里统一一种风格就行。



## 四、变量与作用域

### 4.1 声明

```text
变量 金币 = 100          // var/let/变量 等价
const 折扣 = 0.8         // const/常量 —— 语义上不可变
临时 = 5                 // 不声明直接赋值也行（写入局部）
```

### 4.2 四个名字空间

这是 DreamLang 最重要的概念，页面脚本的一切数据流动都围绕它：

| 前缀 | 是什么 | 谁写入 |
|---|---|---|
| *(裸名)* | 脚本局部变量 | 你的脚本 |
| `vars.xxx` | 页面变量 | 页面顶层键、state_patch 下发 |
| `global.xxx` | 服务端全局变量 | 服务端广播（在线人数等） |
| `player.xxx` / `papi.xxx` | 玩家上下文/占位符 | 引擎注入 |

解析顺序：**局部优先 → 父作用域 → 页面变量**。
所以你写 `金币` 时如果页面恰好有个 `金币` 变量，读到的可能是页面的，
想确定用局部就给变量起个不撞车的名字。

#### 两种写入，行为完全不同（重要）

```text
计数 = 计数 + 1        // 裸赋值：名字已在祖先作用域声明 → 改写那里（闭包修改外部）
                       // 未声明过 → 当前作用域新建
变量 计数2 = 5         // 声明：一律在当前作用域新建，绝不覆盖外层同名变量
```

另外 `vars / global / player / papi` 是保留命名空间前缀，直接赋值会报错：
改页面变量走服务端 state_patch 或 Screen.设置变量 系列方法，不要硬塞。

### 4.3 子作用域与闭包

函数体、Lambda 体、块都会开子作用域：局部互相隔离，
但 `vars/global/player` 与父共享（闭包捕获的是引用，外面改了里面能看到）。

```text
变量 计数 = 0
函数 加一() {
    计数 = 计数 + 1      // 改的是外层的计数
}
加一()
打印(计数)               // 1
```



## 五、运算符与优先级

从低到高（记不住就加括号，括号永远免费）：

| 优先级 | 运算符 | 说明 |
|---|---|---|
| 1 | `? :` | 三元（DragonCore 血统：`条件 ? 真值 : 假值`）|
| 2 | `??` | 空合并：`a ?? b`，a 非 null 取 a 否则取 b，可链式 |
| 3 | `\|\|` | 或 |
| 4 | `&&` | 与 |
| 5 | `== !=` | 相等 |
| 6 | `> >= < <=` | 比较 |
| 7 | `+ -` | 加减（+ 兼做字符串拼接）|
| 8 | `* / %` | 乘除余 |
| 9 | `! -` | 非负 |

两个特色运算：

```text
名称 = 用户输入 ?? "无名氏"        // 输入为 null 时兜底
a ?? b ?? c                       // 链式：取第一个非 null

文本 | 上限                        // 管道：x | fn 等价 fn(x)，可串
"abc" | ((s) => s + "!")          // → "abc!"
```

赋值是表达式：`if ((计数 = 计数 + 1) > 10) { ... }` 合法但慎用，可读性自负。



## 六、控制流

### 6.1 条件

```text
if (条件) { ... } 否则 { ... }
如果 (a > b) 打印(a)              // 单语句可不带花括号
```

### 6.2 循环（四种）

```text
while (金币 < 100) { 金币 += 1 }              // 当：前测循环
当 (条件) { ... }                              // 中文同款

for (变量 i = 0; i < 10; i++) { ... }         // 经典三段式

循环 (5, {                                     // loop：次数 + 块（龙核血统）
    打印("第" + _ + "次")
})

遍历 (列表, 元素, 下标, 整表) {                 // for_each：值/下标/整表都要给名
    打印(下标 + ":" + 元素)
}
```

`break/跳出` 与 `continue/继续` 在所有循环里可用。

### 6.3 await（异步等待）

```text
等待 ({ 打印("一秒后") }, 1000)
```

配合引擎的调度器实现时序编排；更常用的封装是 `Script.延迟执行(ms, 脚本)`。

### 6.4 return

`return/返回 表达式?`，函数内返回值；页面 Functions 顶层脚本里 return 可提前结束。



## 七、函数与 Lambda

### 7.1 定义与调用

```text
函数 折后价(原价, 数量) {
    返回 原价 * 数量 * 折扣
}
打印(折后价(100, 2))         // 直接调用
```

函数是一等公民：可以赋值给变量、当参数传、存进数组。

### 7.2 Lambda（箭头函数）

```text
(x) => x * 2                 // 表达式体
(a, b) => { 返回 a + b }      // 块体
() => 打印("无参也行")
```

三个主场：`Event.订阅` 的回调、管道右侧、定时器脚本。

### 7.3 调用内置方法的两种姿势

```text
Math.max(1, 2)               // 命名空间.方法(参数)
Str.长度("你好")              // 命名空间大小写敏感
```

服务端旧风格的全局函数走 `方法.` 前缀：`方法.发送消息("hi")`，
那是适配层把旧注册表桥接过来的视图，新代码建议统一用命名空间风格。



## 八、类与命名空间

### 8.1 类

```text
类 商品 {
    变量 名称 = ""
    变量 价格 = 0

    函数 折后(折扣) {
        返回 价格 * 折扣
    }
}

变量 卡 = new 商品()          // hmm——实例化的标准姿势见下
卡.名称 = "钻石"
```

支持 `extends` 继承与 `static` 成员。界面上大多数场景用"映射 + 数组"
（见 §14 菜谱）就够了，类留给复杂玩法逻辑。

### 8.2 命名空间

```text
命名空间 商店 {
    变量 折扣 = 0.9
    函数 售价(原价) { 返回 原价 * 折扣 }
}

打印(商店.售价(100))
```

把一组函数和数据打包成一个前缀，天然防重名。



## 九、模块系统

```text
import "utils.dl"                      // 导入整个模块
import "utils.dl" as 工具              // 起别名
import 工具函数 from "utils.dl"        // 具名导入
import * as 全部 from "utils.dl"       // 全量导入

export 函数 公共工具() { ... }          // 导出单个
export { 函数A, 函数B }                // 批量导出
export default { 主入口 }              // 默认导出
```

`import java "java.util.*"` 打开 Java 互操作的类路径白名单（见 §11）。



## 十、异常处理

```text
尝试 {
    抛出 "自定义错误信息"
} 捕获 (错误) {
    打印("捕获: " + 错误)
} 最后 {
    打印("无论如何都执行")
}
```

try/catch/finally 与 throw/抛出 全套齐活。
主题管线的教训在这里同样适用：**脚本报错只 warn 当前脚本，不炸页面**。



## 十一、Java 互操作

```text
Java.String.valueOf(123)                    // 静态调用
Java("java.lang.Math", "max", 1, 2)         // 反射式调用
new Java.util.ArrayList()                   // 实例化
```

类路径受白名单约束（`import java` 开名单）。能力很强，
但附属作者请优先用 ScriptAPI 注册好的业务方法，白名单方式对玩家脚本更安全。

按端分布：common 两侧都有，client 仅客户端，plugin 仅服务端。
调用格式统一为 `命名空间.方法(参数)`，绝大多数带中文别名。

| `Array` | 19+ | 创建/增删插排筛映射遍历 |

## 十三、在页面里使用

### 13.1 三个落点

```yaml
元素:
  actions: {click: "脚本"}            # 事件响应

Functions:
  open: |-                            # 生命周期
    ...
```

以及主题/页面里的**布局表达式**（`x: "(w-40)/2"`），同一套求值器，
语法相同，但没有语句概念，只算一个值。

### 13.2 数据从哪来到哪去

```
页面变量(vars) ←→ state_patch ←→ 服务端
       ↕ 你的脚本通过 vars.xxx 读写
事件数据注入 vars.event / vars.input
```

记住一条铁律：**要被 state_patch 刷新的数据必须放 vars**，
纯脚本中间量放局部即可。

### 13.3 插值的边界

`{{vars.x}}` 是 YAML 文本层的模板插值（构建期/渲染期替换），
脚本内部不要用它，脚本里直接 `vars.x` 读值。两套机制别混。



## 十四、实战菜谱

### 菜谱 1：防抖搜索

```yaml
search:
  type: input
  input: |-
    Script.防抖(300, "
      变量 结果 = MySearch.查询(text.value)
      Screen.设置元素('result_list', 'text.content', 结果)
```

```yaml
Functions:

      if (hp <= 0) {
        Event.发布('boss_killed', name)
      }
    })
```

```text
# 页面 A（商店）往 global 写，页面 B（背包）实时读

```

```text

```



## 十五、常见坑 FAQ

**Q：为什么 `0.1 + 0.2 != 0.3`？**
双精度浮点的通病。金额比较用范围：`(a - b) < 0.001`。

**Q：读了个不存在的变量，没报错但值怪怪的？**
未定义引用得到 `null`，参与算术会按 0 处理、拼接成 `"null"`。
拿不准就用 `??` 给默认值：`金币 ?? 0`。

**Q：中文变量名在某些地方不认？**
布局表达式与脚本都支持中文标识符；唯一注意 YAML 里含特殊符号的值记得引号。

**Q：字符串和数字相加结果不对？**
`+` 遇到字符串优先拼接：`"1" + 1 = "11"`。算术前显式转换：
`Str`/`Math` 库里有 to_int/to_double 系列。

**Q：脚本改了 `vars.coin` 但界面没刷新？**
客户端本地改 vars 只影响本地显示；多人模式下权威数据走服务端
state_patch 下发才会同步到所有查看者。

**Q：能写递归吗？**
能，函数是一等公民。深度过大照样栈溢出，异常会被 try/catch 捕获。
