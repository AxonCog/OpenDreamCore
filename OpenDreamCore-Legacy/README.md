老版本线，1.6.4 到 1.16.5，全是 Forge，全是 Java 8。

## 老版本要注意什么

- **工具链**：Gradle 2.x/4.x + 老 ForgeGradle，现代插件一个都别想用
- **网络协议**：跨版本完全不通，各版本独立跑
- **渲染**：从 GL11 到 GlStateManager 到 BufferBuilder，每个时代一套 API
- **common 复用**：能复用，但得管住手别用 JDK 9+ 的 API

不急，先把现代版搞利索了再说。
