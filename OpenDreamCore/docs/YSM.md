# YSM 模型格式

两层结构：外层 YSGP 容器，内层模型本体。v1/v2 有容器和加密，v3 起容器消失、文件直接是二进制流。

## 容器（YSGP）

- 魔数 `YSGP`，紧随 1 字节版本号（1/2/3）。v3 没有容器，直接进本体。
- v1：`SHA-256(key)[:16]` 当密钥、文件头 16 字节当 IV，AES/CBC/PKCS5 解密；
  v2：SHA-256 派生 32 字节密钥、IV 藏在文件尾 16 字节，AES/CBC。
- 解密后是 zlib 流，摊开是 zip；zip 里 geometry json、动画 json、贴图散放。
- md5 校验：容器头里有原始明文的 md5，解密后比对，不符直接拒。
- 全程 JCE 自实现，无第三方依赖（`YsgpUnpacker`）。

## 二进制本体（v3）

通用编码：varint（LEB128）、长度前缀 UTF-8 串、小端 float。

- 文件头：int32 格式号（≥20 视为本体流）。
- 贴图：PNG 原样内嵌。段与段之间没有长度表，靠 PNG 魔数扫描；
  回溯 1–3 字节 varint 若等于 PNG 长度，即是长度字段；再往前可选
  `[0x40][64 hex]` 哈希与名字串。
- 骨骼段：`[0x40][sha256 十六进制 64 字符][骨数]`，然后逐骨：
  `[parent 名][立方体数]{立方体}[骨名][5 未知 varint][pivot 3×f32][rotation 3×f32 弧度]`。
  立方体 = `[面数]{每面: 法线 3×f32 + 4 顶点×(3×f32 位置 + 2×f32 UV)}[3 未知 varint]`。
- 一个文件可有多个子实体模型（本体/载具/投掷物），各自带骨骼段；取骨数最多的当主模型。
- 动画：平铺流，每条 `[flag][flag==2 则 64hex 哈希 + 未知 varint][名][时长 f32 tick]
  [loop 0/1/2][保留 0][保留 0][混合权重…][0][骨数]{骨: 名 + rotation/position/scale 三通道}
  [timeline][fmt>9: sound_effects]`。
  通道 = `[帧数]{每帧: 时间 f32 + 插值标记 + 三分量(0/1=数值, 2=molang 串) + pre 字节}`。
- loop 语义：0 播一次、1 循环、2 定格末帧。

## 解析策略

本体没有总目录，靠锚点扫描：PNG 魔数（贴图）、hex 串 + 合理骨数 + 逐骨试解（骨骼）、
可读动画名 + 头部校验（动画）。锚点试解失败就换下一个，全部失败抛错跳过该文件。
扫描过程每一步都有数值范围与可读性校验，坏数据不会被当成正常结构吞掉。

`YsmCodec` 对外只暴露 `decode(byte[])`；字符串入口会直接抛错（YSM 是二进制格式）。

## 验证

- `YsgpUnpackerTest`：自造 v1/v2 容器全链加解密往返。
- `YsmCodecTest`：自造最小 v3 字节流往返（1 骨 1 面 1 动画）；
  本机有真实 .ysm 样本时跑真样本，断言骨骼/贴图/动画三者齐全且动画绑到骨骼。
